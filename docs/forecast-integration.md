# 예측 서비스 연결 준비

현재 AI 모델 서버나 운영 예측 API는 구현하지 않습니다. 기존 현재 수량 검색을 기본으로 두고, 목록과 상세에서 같은 API를 사용할 연결 구조를 제공합니다.

## 활성화

루트 `.env`에 `VITE_FORECAST_API_PATH=/stations/forecasts`를 설정하고 웹 서버를 재시작하거나 다시 빌드합니다. Axios 기본 경로가 `/api/v1`이므로 실제 요청은 `POST /api/v1/stations/forecasts`입니다. 운영 시 백엔드에서 이 경로를 제공하거나 AI 서비스로 프록시해야 합니다. 브라우저에 AI 서비스 비밀 키를 넣지 않습니다. 미설정 시 목록의 예측 선택 UI와 네트워크 요청은 비활성입니다.

## API 계약

요청은 `{ "stationIds": ["ST-001"], "horizons": [5,10,15,30,60] }`입니다. 목록 전체를 정렬한 후 5곳을 표시하기 위해, 표시 후보 전체를 최대 100개씩 나누어 조회합니다. 중복 ID는 제거하고 화면 전환 시 취소 신호를 전달합니다.

응답 예시(시각은 매 요청 시 실제 기준으로 생성):

```json
{"data":[{"stationId":"ST-001","baseTime":"2026-10-19T03:00:00Z","generatedAt":"2026-10-19T03:00:10Z","modelVersion":"example-v1","dataStatus":"fresh","predictions":[{"targetTime":"2026-10-19T03:15:00Z","expectedBikes":3.2}]}]}
```

누락 대여소는 응답에서 생략하거나 `dataStatus`를 `unavailable`로 반환할 수 있습니다. 수량은 음수가 아닌 유한 숫자, 시각은 시간대가 포함된 ISO 8601 형식이어야 합니다. 모델 이름과 생성 시각은 추적용입니다.

## 화면 정책

- 기본은 현재 수량. 사용자가 선택한 N분 후는 현재 시각 + N분이며 실제 경로 도착 시간과는 별개입니다.
- 기준 데이터 10분 초과, 미래 30초 초과, 목표 시각 오차 2.5분 초과, 잘못된 수량은 사용하지 않습니다.
- 유효한 예상 수량을 반올림하여 1대 이상 → 0대 → 예측 없음 순으로, 그룹 안에서는 거리순으로 정렬·필터링합니다.
- 전체 누락·지연·API 오류 시 현재 수량 정렬로 복귀하며 안내합니다. 일부 누락이면 해당 대여소를 마지막에 표시합니다.
- 현재 수량은 카드에서 유지하고 예상 수량은 별도 줄에 표시합니다. 예측은 대여를 보장하지 않습니다.
- 지도 마커, 실제 길찾기 대여 가능 여부는 계속 현재 재고 기준입니다.
- 목록은 1분 간격으로 재조회하며 검색 후보 집합을 캐시 키로 사용합니다.

## 이후 구현

AI 서빙 API, 관측 데이터 및 모델 버전 관리, 배치 추론, 품질 평가와 모니터링을 추가한 후 위 계약에 맞는 응답을 연결합니다. 이 문서의 예시 값을 실제 예측처럼 반환하지 않습니다.
