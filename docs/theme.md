# 화면 테마

- 자동 모드는 사용자 기기의 현지 시간을 사용한다. 07:00부터 18:59까지 라이트, 19:00부터 다음날 06:59까지 다크다.
- 저장된 선택이 없으면 30초마다 시간을 확인하며, 탭 복귀 시에도 갱신한다.
- 헤더의 달/해 버튼은 전환할 모드를 나타낸다. 버튼으로 고른 값은 `ddareungrider:theme:v1`에 저장하며 이후 시간대보다 우선한다.
- 저장소 접근이 차단되어도 현재 세션에서 전환할 수 있다. 다른 탭에서 변경한 값도 반영한다.
- 초기 HTML에서 테마를 먼저 정해 밝은 화면이 잠깐 표시되는 현상을 줄인다. 시간 경계를 바꿀 때는 `index.html`과 `src/lib/theme.ts`를 함께 수정한다.

## 지도

다크 모드에서는 Kakao 래스터 지도 타일 이미지에만 CSS 필터를 적용한다. 지도 전체 컨테이너에는 필터를 적용하지 않으므로 지도 로고, 저작권 표시, 커스텀 마커와 경로선은 영향을 받지 않는다. 경로선은 별도 색상을 사용하며 테마를 변경해도 지도 중심과 확대 수준을 유지한다.

SDK의 타일 URL 구조가 바뀌면 `style.css`의 `/tile/` 선택자를 점검해야 한다. 이미지 타일이 매칭되지 않으면 원래 지도가 표시된다.

참고: [Kakao의 CSS 필터 및 브랜드 표시 관련 안내](https://devtalk.kakao.com/t/api-css/146035).

## 검증

`npm --prefix Ddareungi-rider/web test`에 자동 전환 경계, 수동 선택 우선순위, 잘못된 저장값과 저장소 오류 검증을 포함한다. 브라우저에서는 시간 경계 전후, 새로고침 유지, 다른 탭 변경, 테마 전환 중 지도 중심과 경로 유지 및 로고/저작권에 필터가 적용되지 않는지 확인한다.
