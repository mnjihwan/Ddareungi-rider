# 지도에서 장소 선택


## 지도 장소 마커 선택

길찾기 입력 중 음식점·카페·편의점·지하철역을 Kakao 장소 API에서 조회해 선택 가능한 장소 마커를 표시한다. 마커를 누르면 실제 장소 이름과 주소, 출발지/도착지 지정 버튼만 표시한다. 배경지도에 인쇄된 상호명이나 임의 좌표에서 가게를 추정하지 않는다.

- 조회 범위: 지도 중심 반경 500m, 카테고리별 최대 8개, 총 최대 32개. 지도 레벨 4 이하에서 조회한다.
- 지도 이동 후 600ms 대기하며 중심을 약 10m 격자로 묶어 같은 지역의 잦은 요청을 줄인다. 프론트 조회 결과는 60초간 재사용한다.
- 실제 화면에서는 겹치는 이름을 제거해 최대 16개를 표시한다. 화면 밖/이름·주소 누락 장소는 표시하지 않는다.
- 선택한 장소의 원래 이름·주소·좌표를 경로 입력에 전달하며, 임의 좌표로 대체하지 않는다.
- 경로 검색 중/결과 표시 중에는 장소 마커를 숨긴다. 모바일에서는 장소 선택 시 목록을 내려 지도와 선택창을 보여준다.
- 한 카테고리 조회 실패 시 나머지 결과를 유지하고, 모두 실패하면 일반화된 오류를 반환한다. API 키와 외부 오류 본문은 노출하지 않는다.
