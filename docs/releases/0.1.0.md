# v0.1.0 — 1차 웹 기능 릴리스

릴리스 날짜: 2026-10-19. PC·모바일 브라우저에서 현재 수량을 기준으로 대여소를 찾고 길찾기를 사용하는 첫 기능 릴리스입니다.

## 포함 기능

- 카카오 지도, 현재 위치·지도 위치 선택, 주변 대여소와 현재 자전거 수량 조회.
- 장소·주소·대여소 검색, 자동완성, 한영 키·초성·제한적인 오타 보정.
- 즐겨찾기, 최근 검색, 출발·도착 위치 및 대여소 선택.
- 서비스 내부의 도보→따릉이→도보 길찾기.
- PC·모바일 반응형 화면, 지도 마커와 수량 표시, 라이트·다크 테마.
- 서울시 데이터 수집, MySQL 적재, Redis 최신 수량 갱신 및 결측 수량 구분.

## 예측 및 별도 범위

AI 대여·반납 수요 실험 소스는 포함되지만 미래 잔여 수량 예측 모델·서빙 API·웹 연결은 구현 전입니다. 예측 API 미설정 시 화면은 준비 중 안내와 현재 수량을 제공합니다. Elasticsearch는 실행 구성에 포함하지 않습니다. 기존 Expo 모바일 코드는 PoC 보관본이며 현재 제공 대상은 웹입니다.

이번 릴리스의 main 반영은 운영 환경 배포를 의미하지 않습니다. 운영 부하·외부 API 지연 및 호출 수, 장기간 연속 수집 품질, 실제 휴대폰 현장 주행 검증은 후속 과제입니다.

2026-10-19 릴리스 준비 시 확인한 결과:

| 실행 경로 | PowerShell 스크립트 구문 검사, 최신 실행 JAR 선택 확인. Docker COPY를 정식 버전 JAR에도 대응하도록 수정 |

총 132개 테스트가 통과했습니다. 이번 검증에서는 실제 외부 API 브라우저 통합 테스트와 DB 재수집을 새로 실행하지 않았습니다. 이전 실제 API·PC·모바일 검증 범위는 README의 날짜별 기록을 참고하세요.

`release/0.1.0`에서 준비한 뒤 두 저장소의 `main`에 병합합니다. 이번 원격 반영 범위는 `main`이며, `develop` 동기화와 원격 버전 태그 게시는 별도 후속 작업입니다. 통합 저장소는 수집기의 고정 커밋을 submodule로 참조합니다. 비밀키·원본 데이터·학습 모델·로컬 이미지 작업 산출물은 릴리스에 추가하지 않습니다.
